# Состояние проекта

Обновлено: 2026-09-09. Читается первым; подробности — по ссылкам.

## Коротко

Приложение работает на **настоящих данных**: цепочка `extract → enrich → build`
собирает `content.sqlite` из выгрузки OSM и текстов Wikipedia, приложение
открывает эту базу из assets. По району Бергена — 1183 места, 17 городов.

Нет фотографий, поиска, локализации интерфейса и данных по остальной стране.

## Сделано

### Приложение (Flutter, Этап 1)

| Что | Где |
|---|---|
| Стартовый экран с заставкой и двумя путями | `app/lib/features/home/` |
| «Рядом со мной»: расстояние, направление, фильтры | `app/lib/features/nearby/` |
| Города и места города | `app/lib/features/cities/` |

| Схема БД и запросы с fallback | `app/lib/data/` |

Подробнее: [[architecture]], [[data-model]].

### Пайплайн (Go)

| Команда | Состояние |
|---|---|
| `cmd/probe` | готова — разведка покрытия контента |
| `cmd/extract` | готова — OSM → JSONL, категории, значимость |
| `cmd/enrich` | готова — Wikidata + тексты, 97% покрытия топ-40 |
| `cmd/build` | готова — `content.sqlite` 0,9 МБ по Бергену |
| `cmd/media` | следующая — фото с Commons |
| `cmd/preview` | превью карты для карточек |

Цепочка `extract → enrich → build` работает целиком. Схема собранной базы
совпадает со схемой drift, запросы приложения проверены тестами
(`pipeline/cmd/build/verify_test.go`).

## Не сделано

  впереди: [[pipeline-plan]]
- **Локализация интерфейса** — строки зашиты в коде по-русски, `.arb` не заведены
- **Поиск** — FTS5 в схеме есть, экрана поиска нет
- **Маршруты** — таблицы есть, экрана нет
- **Фото** — таблица есть, изображений нет
- **Сохранение состояния** — профиль и выбранный город живут только в памяти
- **Интерактивная карта** — вынесена в Этап 6

## Известные ограничения

- В базе только район Бергена: 1183 места, 17 городов. При выборе Тромсё
  или Киркенеса список закономерно пуст — сборка по всей стране ещё не
  запускалась.
- Тексты есть у 39 мест: `enrich` гонялся с `--limit 40`.
- Тестовые данные `seed_data.dart` остались как запасной вариант и
  подставляются, только если база пуста.
- Разработка идёт на web; офлайн-поведение, размер сборки и производительность
  там не проверяются — только на устройстве ([[development#Где что проверяется]]).
- Android SDK не установлен, сборки под телефон пока нет.

## Как продолжить работу после перерыва

Проверить, что всё на месте:

```powershell
cd E:\NorwayTourGuide\app
flutter analyze     # ожидается: No issues found
flutter test        # ожидается: 6 тестов, все зелёные
flutter run -d chrome --web-port=8080
```

Если `flutter` или `go` не находятся, они лежат в `E:\dev\flutter\bin`
и `C:\Program Files\Go\bin` — оба прописаны в системном PATH, но сессия
терминала, запущенная до их установки, о них не знает.

Файлы `app/web/sqlite3.wasm` и `app/web/drift_worker.js` лежат в репозитории
и должны соответствовать версии drift из `pubspec.lock` (сейчас 2.34.4).
При обновлении drift их надо перекачать с
`https://github.com/simolus3/drift/releases/download/drift-<версия>/`.

Выгрузка OSM (1.3 ГБ) уже в `pipeline/data/`, в git не входит. Если каталог
пуст — команда скачивания в [[development#Данные]].
