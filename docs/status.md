# Состояние проекта

Обновлено: 2026-09-09. Читается первым; подробности — по ссылкам.

## Коротко

Работает приложение на тестовых данных: стартовый экран, список ближайших мест
с расстоянием и направлением, города, карточка места, избранное, профили
интересов. Настоящего контента ещё нет — [[pipeline-plan|пайплайн]] не написан.

## Сделано

### Приложение (Flutter, Этап 1)

| Что | Где |
|---|---|
| Стартовый экран с заставкой и двумя путями | `app/lib/features/home/` |
| «Рядом со мной»: расстояние, направление, фильтры | `app/lib/features/nearby/` |
| Города и места города | `app/lib/features/cities/` |
| Карточка места, избранное, внешняя навигация | `app/lib/features/place/` |
| Профили интересов и ранжирование | `app/lib/core/profile.dart` |
| Схема БД и запросы с fallback | `app/lib/data/` |

Подробнее: [[architecture]], [[data-model]].

### Проверки рисков

- [[probe-result]] — контент есть: 90–100% покрытия по городам, риск снят
- [[measurements]] — тайлы z0–12 весят 472 МБ вместо 180 МБ, карта вынесена
  за пределы MVP ([[decisions#Карта вне MVP]])

### Инфраструктура

Go 1.27.1, Flutter 3.47.2, Java 17 (Temurin), выгрузка `norway-latest.osm.pbf`
(1.3 ГБ). Подробнее: [[development]].

## Не сделано

- **Пайплайн данных** — есть только `cmd/probe`. Основная работа Этапа 0
  впереди: [[pipeline-plan]]
- **Локализация интерфейса** — строки зашиты в коде по-русски, `.arb` не заведены
- **Поиск** — FTS5 в схеме есть, экрана поиска нет
- **Маршруты** — таблицы есть, экрана нет
- **Фото** — таблица есть, изображений нет
- **Сохранение состояния** — профиль и выбранный город живут только в памяти
- **Интерактивная карта** — вынесена в Этап 6

## Известные ограничения

- Мест в базе 15, городов 3 — тестовые данные. При выборе Тромсё или Киркенеса
  список закономерно пуст.
- Разработка идёт на web; офлайн-поведение, размер сборки и производительность
  там не проверяются — только на устройстве ([[development#Где что проверяется]]).
- Android SDK не установлен, сборки под телефон пока нет.
