# Состояние проекта

Обновлено: 2026-09-11. Читается первым; подробности — по ссылкам.

## Коротко

Приложение называется **Norway Explore** (внутреннее имя пакета —
`nordguide`) и работает на настоящих данных по всей Норвегии: **3 342 места,
660 городов, 3 236 мест с описаниями (96%), 2 798 фотографий**.
База 22,9 МБ, снимки 99,5 МБ. Есть поиск, избранное, экстренная помощь,
топ-25 самых посещаемых мест, интерфейс на шести языках.
APK **48,8 МБ** (arm64) — в бюджете §5 спеки.

Каталог сократился с 66 910 до 3 342 намеренно: место без описания и без
фотографии — это строка с названием и координатами, и таких в OSM было 98%
(см. [[decisions#В базу попадают только места с описанием или фотографией]]).

**Проверено на реальном устройстве** (Galaxy S20 FE, Android 13):
работает офлайн при выключенных Wi-Fi и мобильных данных, внешняя
навигация открывается. Нет маршрутов, пакетов обновления и сохранения
состояния между запусками.

### Пайплайн (Go)

| Команда | Состояние |
|---|---|
| `cmd/probe` | разведка покрытия контента |
| `cmd/extract` | OSM → JSONL: 66 910 мест за 59 секунд |
| `cmd/enrich` | Wikidata + тексты, 98% покрытия отобранных |
| `cmd/media` | фото с Commons с проверкой лицензий |
| `cmd/build` | сборка `content.sqlite` |
| `cmd/inspect` | заглянуть в базу глазами приложения |
| `cmd/preview` | не написана — превью карты для карточек |

Цепочка `extract → enrich → media → build` работает целиком. Схема
собранной базы совпадает со схемой drift, запросы приложения проверены
тестами (`pipeline/cmd/build/verify_test.go`).

## Известные ограничения

- Каталог — 3 342 места: только те, о которых есть что сказать. Расширять
  его теперь можно обогащением, а не разметкой OSM. Экран «Рядом со мной»
  в глухих местах может оказаться пустым — это честный ответ, и он
  предлагает перейти к городам.
- Фотографии у 2 798 объектов; где их нет, карточка показывает заливку
  цветом категории.
- Галереи из нескольких снимков есть у мест курируемого топ-25. Файлы берутся из
  категории Commons и проходят проверку на релевантность по названию:
  без неё в парк Вигеланна попал снимок нацистского партийного съезда,
  лежавший в той же категории. Фильтр грубый и теряет часть хороших
  кадров с описательными названиями.
- Снимки — JPEG 480 px, а не WebP, как просит спека: кодировщик WebP
  в Go требует C-библиотеки. Экономия была бы ещё около трети.
- В бандле осталось 417 снимков (14,7 МБ) — топ-25 и города. Остальные
  2 383 уехали в региональные пакеты и качаются по кнопке.
- Около 40 сельских церквей остались без фото: Wikimedia отвечает
  `HTTP 429` при массовой закачке. Добираются повторным прогоном `media`.
- Отзывов нет и не будет: свободных источников не существует
  ([[decisions#Отзывов в приложении не будет]]).
- Описания мест есть на шести языках, но покрытие разное: норвежский
  3 074, английский 2 316, немецкий 452, испанский 266, китайский 219,
  русский 187. Статьи в Wikipedia о норвежских местах на этих языках
  просто редки — для значимых мест находятся примерно у пятой части.
  Где перевода нет, работает цепочка подстановки (§8.4) и стоит пометка
  «описание на другом языке».
- Испанский и китайский переводы интерфейса стоит показать носителю:
  грамматически верны, естественность не гарантирована.
- Разработка идёт на web; офлайн-поведение и производительность там
  не проверяются ([[development#Где что проверяется]]).

## Как продолжить работу после перерыва

```powershell
cd E:\NorwayTourGuide\app
flutter analyze              # ожидается: No issues found
flutter test --concurrency=1 # ожидается: 52 теста, все зелёные
flutter run -d chrome        # разработка
flutter build apk --release --split-per-abi   # сборка под телефон
```

**Тесты приходится гонять по файлам.** Общий прогон падает с «did not
complete» — тестовые изоляты конфликтуют между файлами (предположительно
на моках `shared_preferences`). Каждый файл по отдельности проходит
полностью, все 52 теста зелёные:

```powershell
foreach ($f in Get-ChildItem test\*.dart) { flutter test $f }
```

Проблема в окружении, не в коде, но её стоит решить до появления CI —
иначе прогон там не настроить.

**Тесты и `flutter run` не уживаются**: запущенный dev-сервер держит
блокировку, и тесты падают так же. Останавливать сервер перед прогоном.

Инструменты: `E:\dev\flutter\bin`, `E:\dev\android-sdk`,
`C:\Program Files\Go\bin`, `C:\Program Files\Eclipse Adoptium`.
Все прописаны в системном PATH, но сессия терминала, запущенная до
установки, о них не знает.

Файлы `app/web/sqlite3.wasm` и `app/web/drift_worker.js` должны
соответствовать версии drift из `pubspec.lock` (сейчас 2.34.4).

Пересобрать данные: команды в [[development#Сборка контента и подключение к приложению]].
