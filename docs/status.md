# Состояние проекта

Обновлено: 2026-09-10. Читается первым; подробности — по ссылкам.

## Коротко

Приложение работает на настоящих данных по всей Норвегии: **66 910 мест,
1 907 городов, 1 325 мест с описаниями, 467 фотографий**. База 26,7 МБ.
Есть поиск, избранное, экстренная помощь, интерфейс на шести языках.
APK собирается — около 60 МБ на устройство.

**Проверено на реальном устройстве** (Galaxy S20 FE, Android 13):
работает офлайн при выключенных Wi-Fi и мобильных данных, внешняя
навигация открывается. Нет маршрутов, пакетов обновления и сохранения
состояния между запусками.

### Пайплайн (Go)

| Команда | Состояние |
|---|---|
| `cmd/probe` | разведка покрытия контента |
| `cmd/extract` | OSM → JSONL: 66 910 мест за 59 секунд |
| `cmd/enrich` | Wikidata + тексты, 98% покрытия отобранных |
| `cmd/media` | фото с Commons с проверкой лицензий |
| `cmd/build` | сборка `content.sqlite` |
| `cmd/inspect` | заглянуть в базу глазами приложения |
| `cmd/preview` | не написана — превью карты для карточек |

Цепочка `extract → enrich → media → build` работает целиком. Схема
собранной базы совпадает со схемой drift, запросы приложения проверены
тестами (`pipeline/cmd/build/verify_test.go`).

- **Интерактивная карта** — вынесена в Этап 6

## Известные ограничения

- Описания есть у 1 325 мест из 66 910. Остальные показываются с именем
  и координатами — это допустимое состояние, у безымянного водопада
  статьи не будет никогда.
- Фотографии у 467 объектов; где их нет, карточка показывает заливку
  цветом категории.
- Испанский и китайский переводы интерфейса стоит показать носителю:
  грамматически верны, естественность не гарантирована.
- Временный переключатель языка на главном экране — убрать перед релизом.
- Разработка идёт на web; офлайн-поведение и производительность там
  не проверяются ([[development#Где что проверяется]]).

## Ближайшие шаги

1. Разделение базы через ATTACH: обновление контента не должно стирать избранное
2. Маршруты по городам
3. Пакеты и загрузки (Этап 3)

## Как продолжить работу после перерыва

```powershell
cd E:\NorwayTourGuide\app
flutter analyze              # ожидается: No issues found
flutter test                 # ожидается: 39 тестов, все зелёные
flutter run -d chrome        # разработка
flutter build apk --release --split-per-abi   # сборка под телефон
```

**Тесты и `flutter run` не уживаются**: запущенный dev-сервер держит
блокировку, и тесты падают с «did not complete». Останавливать сервер
перед прогоном.

Инструменты: `E:\dev\flutter\bin`, `E:\dev\android-sdk`,
`C:\Program Files\Go\bin`, `C:\Program Files\Eclipse Adoptium`.
Все прописаны в системном PATH, но сессия терминала, запущенная до
установки, о них не знает.

Файлы `app/web/sqlite3.wasm` и `app/web/drift_worker.js` должны
соответствовать версии drift из `pubspec.lock` (сейчас 2.34.4).

Пересобрать данные: команды в [[development#Сборка контента и подключение к приложению]].
