# Проверка на iPhone

Как получить сборку и поставить её на устройство, не имея Mac.

## Почему это не так просто, как с Android

С Android всё прямолинейно: `flutter build apk`, файл по USB, установка.
С iOS мешают два независимых ограничения Apple.

**Собрать можно только на macOS.** Xcode под Windows не существует и
никогда не существовал. Обойти нечем: кросс-компиляция iOS-приложений
вне macOS не поддерживается принципиально.

**Поставить можно только подписанное.** Даже собранный `.ipa` iPhone
не примет, пока приложение не подписано сертификатом, привязанным
к конкретному устройству или к учётной записи разработчика.

## Как получить сборку

Сборка идёт на арендованном macOS-раннере GitHub — файл
`.github/workflows/ios.yml`.

1. Открыть репозиторий на GitHub → вкладка **Actions**
2. Слева выбрать **iOS build** → кнопка **Run workflow**
3. Дождаться окончания (примерно 10–15 минут)
4. Внизу страницы прогона забрать артефакт
   **NorwayExplore-ios-unsigned**

Внутри — `.ipa` без подписи.

Сборка запускается только вручную, кнопкой. Автоматически на каждый
коммит не вешаем: минуты macOS-раннера списываются в десятикратном
размере от обычных, и очередь сборок съела бы месячный лимит за день.

## Как поставить на iPhone

Дальше выбор из трёх путей, и он зависит от того, есть ли платная
учётная запись Apple Developer.

### Без платной учётной записи: Sideloadly

Бесплатно, ставится с обычного компьютера, но приложение живёт **7 дней**,
после чего перестаёт запускаться и его нужно переустановить.

Нужен компьютер (Windows подойдёт), кабель и обычный Apple ID.

1. Поставить [Sideloadly](https://sideloadly.io/)
2. Подключить iPhone кабелем, доверить компьютеру
3. Перетащить `.ipa` в окно Sideloadly, ввести свой Apple ID
4. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   найти свой профиль разработчика → **Доверять**

Про Apple ID: Sideloadly просит его, чтобы выпустить временный сертификат
разработчика. Если не хотите вводить основной — Apple разрешает завести
отдельный бесплатный ID, он подойдёт.

Ограничения бесплатной подписи: не больше трёх приложений одновременно
и семь дней на каждое. Для проверки этого достаточно.

### С платной учётной записью ($99 в год): TestFlight

Правильный путь для регулярной проверки и для тестировщиков, которым
не хочется возиться с кабелем.

1. Зарегистрировать Apple Developer Program
2. Создать App ID `com.nordguide.nordguide` в App Store Connect
3. Добавить в workflow сертификат и provisioning profile (через секреты
   репозитория), заменить `--no-codesign` на подпись
4. Сборка уезжает в TestFlight, тестировщики получают приглашение
   по почте и ставят приложение обычной кнопкой

Ставится на любое число устройств, живёт 90 дней, обновляется само.

### Ad-hoc: подпись под конкретные устройства

Тоже требует платной учётной записи. В профиль вносятся UDID устройств
(до 100), `.ipa` подписывается под них и ставится без TestFlight.
Смысл имеет, когда устройств несколько и они известны заранее.

## Что уже готово к iOS

- **Разрешение геолокации** в `Info.plist` с объяснением на шести языках
  (`ios/Runner/*.lproj/InfoPlist.strings`). Без него iOS не показывает
  системный запрос вовсе, и определение молча не работает — ровно эта
  ошибка уже случалась на Android.
- **Иконки** всех пятнадцати размеров, которых требует Apple, собираются
  командой `go run ./cmd/appart ios-icons`. Без прозрачности: App Store
  Connect отклоняет иконки с альфа-каналом при загрузке.
- **Имя приложения** — Norway Explore, в `CFBundleDisplayName`
  и `CFBundleName`.
- **ATS**: произвольный HTTP запрещён. Исключение для локальной раздачи
  пакетов есть только в Android-сборке и в iOS не переносится.

## Чего ждать при первом запуске на iPhone

Приложение ни разу не запускалось на устройстве Apple, поэтому список
вероятных мест, где оно споткнётся:

- **Права на файлы.** База копируется в каталог документов, а пакеты —
  в `Application Support`. На iOS у них разные правила резервного
  копирования: контент не должен уезжать в iCloud, а пользовательские
  данные — должен. Пометка `NSURLIsExcludedFromBackupKey` пока не
  проставлена.
- **Геолокация.** Разрешение объявлено, но диалог на живом устройстве
  не проверялся.
- **Шрифты и вёрстка.** Экраны проверялись на Android 360×640 и
  Galaxy S20 FE; на узком iPhone SE возможны переполнения.
