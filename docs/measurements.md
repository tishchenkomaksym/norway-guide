## Тайлы карты

**2026-09-09.** Метод: вырезка из планетарной сборки Protomaps
(`20260909.pmtiles`, 128,4 ГБ) по HTTP Range — качаются только нужные тайлы,
Planetiler не запускался.

| Что | Результат |
|---|---|
| `z0–12`, bbox `4.0,57.9,31.6,71.4` | оборвалось на 1 091,6 МБ (90%) |
| `z0–12`, обрезка по границе Норвегии | **472 МБ** |
| Оценка в §5 спеки | ~180 МБ |
| Передано данных | 519 МБ за 125 запросов, overfetch 0.05 |

Первый замер завышен: прямоугольный bbox накрыл Швецию, Финляндию, часть
России и Балтику. Норвегия узкая и изогнутая, прямоугольник ей не подходит.

**Вывод.** Реальность в 2,6 раза тяжелее оценки. Бюджет базового пакета
не сходится → [[decisions#Карта вне MVP]].

`z13–14` не замерены: смысла нет, пока карта вне MVP. Вернуть к Этапу 6.

Отдельное наблюдение: Protomaps отдаёт полный базовый слой — здания,
землепользование, вся дорожная сеть. Гиду это не нужно. Если карта вернётся,
собственная генерация с урезанным набором слоёв может дать заметно меньший вес.

## Размеры бандла

Плановые, не измеренные — приложение ещё не собиралось под стор.

| Компонент | Цель |
|---|---|
| Бандл в сторе | 40–60 МБ |
| Стартовая БД: POI, координаты, короткие `summary` на `en`+`no` | ~30–40 МБ |
| Превью топ-1000 мест | 20–40 МБ |
| Региональный пакет: фото и полные тексты | 150–400 МБ |

Внешние ограничения, которые нельзя обойти: Google Play — 200 МБ на AAB
(свыше 150 МБ нужно одобрение); App Store — лимит сотовой загрузки ~200 МБ,
выше только по Wi-Fi, что убивает конверсию.

## Что ещё предстоит замерить

- **Доля POI с тегом `wikidata`** — на первом прогоне `cmd/extract`.
  Вся схема обогащения держится на этом теге; если он у 15% объектов,
  большинство мест останется без описаний. Открытый риск.
- **Доля отбраковки фото по лицензии** — на первых 200 снимках из Commons.
- **Фактический размер `content.sqlite`** против бюджета ~40 МБ.
- **Время холодного старта и отклик списка** на реальном Android.
