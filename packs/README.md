# Манифест раздачи

`manifest.json` — единственный файл, который приложение скачивает первым.
В нём перечислены региональные пакеты фотографий: адрес, размер,
контрольная сумма и версия.

## Почему он лежит в репозитории

Сами пакеты весят 85 МБ и в git им не место — они выкладываются
вложениями к релизу. А манифест занимает три килобайта и меняется при
каждой пересборке пакетов, поэтому его удобнее держать здесь: обновление
раздачи становится обычным коммитом, без ручной загрузки файлов.

Приложение читает его по адресу
`raw.githubusercontent.com/<репозиторий>/main/packs/manifest.json`.

## Адреса пакетов

Поле `file` может содержать как имя файла, так и полную ссылку. Второе
используется сейчас: пакеты выложены вложениями и получили несоседние
адреса. Приложению это безразлично — оно идёт по тому, что записано
в манифесте.

Отсюда же следует приятное свойство: раздачу можно перевезти на другой
хост (например, на Cloudflare R2, как записано в decisions.md), поменяв
только этот файл. Пересобирать и перевыпускать приложение не придётся.

## Как обновить

```powershell
cd pipeline
go run ./cmd/pack --pack-version 2     # собрать пакеты заново
```

Затем выложить `data/packs/*.zip` вложениями к новому релизу, вписать
их адреса в `file` и закоммитить обновлённый манифест сюда.
