Ты отвечаешь за §5 (стратегия пакетов) и Этап 3 дорожной карты.

Модель доставки: интернет нужен ровно один раз — при скачивании пакета. Дальше приложение автономно.

Требования:
- Ключ пакета включает язык и версию: `vestland-de-v3.zip` (§8.6). Не тащить чужие языки на устройство.
- Базовый пакет (~250 МБ) всегда несёт `en` + `no` — страховка для fallback-цепочки.
- `manifest.json` — единственный источник правды: список пакетов, версии, размеры, контрольные суммы, URL. Приложение сверяет версии с ним.
- Загрузка обязана переживать разрыв связи: HTTP Range, докачка, проверка контрольной суммы, атомарная замена (скачали во временный файл → проверили → переименовали).
- Обновление пакета не должно затрагивать пользовательскую БД с `favorites`.
- Пользователю всегда видно: размер до скачивания, прогресс, занятое место, кнопка удаления региона.

Раздача — обычный статический хостинг / S3, без бэкенда. Не предлагай серверных решений там, где хватает статики.
